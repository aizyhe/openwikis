## 🧠 AI 알고리즘 권위 가이드

Transformer에서 기반 모델과 인공지능 시스템까지의 알고리즘 전체 여정을 다루는 권위 가이드. 이론 도출과 엔지니어링 실무를 균형 있게 다루며 2026년 최신 오픈소스 아키텍처를 추적합니다.

- **아키텍처 기초(1-4장)**: Transformer 원리와 데이터 흐름, 텍스트/이미지/음성 토큰화와 위치 인코딩(RoPE, ALiBi), 핵심 컴포넌트(FFN, 정규화), 자기회귀 생성과 디코딩 전략
- **학습과 스케일링(5-9장)**: 학습과 최적화, 사전학습과 데이터(합성 데이터, 스케일링 법칙), 사후 정렬(SFT/RLHF/DPO), 최신 아키텍처(MoE, 하이브리드/선형 어텐션), 선도 모델 사례(DeepSeek-V4, Kimi K3, Qwen 3.8 Max, GLM 5.3)
- **효율적 추론과 생성(10-14장)**: 장문 컨텍스트와 KV Cache, 투기적 디코딩, 강화학습 원리, 추론 강화와 사고사슬, 생성 모델(확산 언어모델), 멀티모달(VLM/VLA)
- **지능형 시스템과 엔지니어링(15-18장)**: 에이전트 시스템과 인지 아키텍처, 세계 모델, 안전성과 평가, FlashAttention의 GPU 수준 고효율 구현

> LLM 알고리즘 엔지니어, NLP/멀티모달 연구자, Transformer 내부와 추론 최적화를 깊이 있게 배우고 싶은 실무자에게 적합합니다.

## ⚡ AI 인프라 권위 가이드

GPU 마이크로아키텍처에서 만 GPU 클러스터까지 AI 인프라 전 과정을 다루는 레퍼런스. NVIDIA, Google, Meta, Microsoft의 공개 기술 보고서와 오픈소스 시스템을 기반으로, 코드 수준의 상세함과 엔지니어링 트레이드오프를 함께 다룹니다.

- **하드웨어와 소프트웨어(1-5장)**: AI 인프라 개요와 스케일링 법칙, GPU 마이크로아키텍처(SIMT/SIMD, SM과 Warp 스케줄링, 메모리 계층, Tensor Core), AI 가속기 생태계(AMD ROCm, Google TPU, 커스텀 실리콘), CUDA와 Triton 고성능 Kernel(FlashAttention, 퓨전 Kernel), ML 컴파일러(PyTorch 2.0, JAX/XLA, TensorRT)
- **학습과 추론(6-11장)**: 분산 학습(DDP/FSDP, 텐서/파이프라인/시퀀스/전문가 병렬), NCCL 집합 통신과 네트워크(NVLink/NVSwitch, InfiniBand/RoCEv2), 학습 시스템 엔지니어링(내결함성, 체크포인트, 혼합 정밀도), 추론 최적화(vLLM, PagedAttention, Continuous Batching, KV Cache), 모델 양자화(GPTQ, AWQ, SmoothQuant)와 압축
- **데이터와 플랫폼(12-15장)**: RAG와 벡터 검색, AI 스토리지와 데이터 엔지니어링, 클러스터 토폴로지와 스케줄링(SLURM, K8s GPU 스케줄링), 클라우드 네이티브 MLOps와 AI 플랫폼
- **측정과 실무(16-18장)**: 성능 지표와 MFU 분석, AI 인프라 이론 계산 핸드북(FLOPs, 메모리 계획, 통신 대역폭, 비용 추정), 대규모 AI 클러스터 구축 실전

> AI 인프라 엔지니어, 학습/추론 플랫폼 개발자, 시스템 아키텍트, 분산 시스템 실무자에게 적합합니다.

## ☁️ 클라우드 컴퓨팅 권위 가이드

가상화에서 멀티클라우드 전략까지 클라우드 컴퓨팅 전 스택 지식 체계. AWS, Azure, GCP, Alibaba Cloud, Tencent Cloud, Huawei Cloud 6대 클라우드 제공업체의 실제 제품을 기반으로 아키텍처 원리와 설계 트레이드오프를 분석합니다.

- **기초(1-3장)**: 클라우드 정의와 경제성, 가상화 기술(CPU/메모리/I/O, KVM과 QEMU), 서비스 모델(IaaS/PaaS/Serverless/CaaS)과 선정 프레임워크
- **리소스 서비스(4-7장)**: 컴퓨트 서비스(인스턴스 패밀리, 오토스케일링, 스팟 인스턴스, 베어메탈), 클라우드 스토리지(블록/오브젝트/파일, 일관성 설계, 백업과 재해복구), 클라우드 네트워킹(VPC, 로드밸런싱, CDN, DNS), 컨테이너 기술(Namespace/Cgroups, 런타임, CNI/CSI, 이미지 배포)
- **플랫폼과 데이터(8-13장)**: 클라우드 네이티브 설계 패턴, Kubernetes 오케스트레이션, 서비스 메시와 마이크로서비스, 클라우드 데이터베이스, 메시징과 이벤트 기반, 빅데이터와 AI
- **거버넌스와 운영(14-18장)**: 클라우드 보안과 규정 준수, 옵저버빌리티, DevOps와 플랫폼 엔지니어링, FinOps 비용 거버넌스, 멀티클라우드 설계와 마이그레이션

> 클라우드 아키텍트, 백엔드 엔지니어, SRE, DevOps 엔지니어, 기술 매니저에게 적합합니다.

## 🦾 엠보디드 인텔리전스 권위 가이드

강체 역학에서 VLA 기반 모델과 로보틱스까지의 체계적 권위 레퍼런스. 제1원리에서 출발해 고전 기법과 최전선을 연결하며, 각 방법을 형식화·수학적 유도·엔지니어링 구현 순서로 설명합니다.

- **기초와 개요(1-3장)**: 정의와 핵심 과학 문제, 강체 운동과 역학(자세 표현, 리 군, 운동학과 동역학, 접촉과 마찰), 로봇 하드웨어와 시스템 아키텍처
- **지각과 제어(4-7장)**: 멀티모달 지각(시각/촉각/힘/고유수용), 상태 추정과 SLAM, 뉴럴 장면 표현, 운동 계획과 모델 예측 제어, 파지와 정교한 조작
- **엠보디드 기반 모델(8-12장)**: 세계 모델, 강화학습, 모방학습(확산 정책, 액션 청킹), 시각-언어 모델(VLM), 시각-언어-행동 모델(VLA)
- **시스템과 배포(13-18장)**: 데이터 엔진과 Sim-to-Real 전이, 학습 인프라, 엣지 배포와 모델 압축, 안전·정렬·평가, 산업 동향과 휴머노이드 로봇 상용화

> 로보틱스, 자율주행, AI 분야 엔지니어·연구자, 엠보디드 인텔리전스 산업화를 주시하는 제품·투자 관계자에게 적합합니다.
