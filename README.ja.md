## 🧠 AIアルゴリズム権威ガイド

Transformerから基盤モデル、インテリジェントシステムまでのアルゴリズム全工程を扱う指南書。理論導出とエンジニアリング実践の両方を重視し、2026年最新のオープンソースアーキテクチャを追跡します。

- **アーキテクチャ基礎（第1-4章）**: Transformerの原理とデータフロー、テキスト/画像/音声のトークン化と位置エンコーディング（RoPE、ALiBi）、コアコンポーネント（FFN、正規化）、自己回帰生成とデコード戦略
- **学習とスケーリング（第5-9章）**: 学習と最適化、事前学習とデータ（合成データ、スケーリング則）、事後アライメント（SFT/RLHF/DPO）、最新アーキテクチャ（MoE、ハイブリッド/線形アテンション）、先端モデル事例（DeepSeek-V4、Kimi K3、Qwen 3.8 Max、GLM 5.3）
- **効率的な推論と生成（第10-14章）**: 長文コンテキストとKV Cache、投機的デコード、強化学習の原理、推論拡張と思考連鎖、生成モデル（拡散言語モデル）、マルチモーダル（VLM/VLA）
- **インテリジェントシステムとエンジニアリング（第15-18章）**: エージェントシステムと認知アーキテクチャ、世界モデル、安全性と評価、FlashAttentionのGPUレベル高効率実装

> LLMアルゴリズムエンジニア、NLP/マルチモーダル研究者、Transformer内部構造と推論最適化を深く学びたい実務者向け。

## ⚡ AIインフラ権威ガイド

GPUマイクロアーキテクチャから万GPUクラスターまでのAIインフラ全工程を扱うリファレンス。NVIDIA、Google、Meta、Microsoftの公開技術レポートとオープンソースシステムを基盤に、コードレベルの詳細とエンジニアリング上のトレードオフを両立します。

- **ハードウェアとソフトウェア（第1-5章）**: AIインフラ概観とスケーリング則、GPUマイクロアーキテクチャ（SIMT/SIMD、SMとWarpスケジューリング、メモリ階層、Tensor Core）、AIアクセラレータエコシステム（AMD ROCm、Google TPU、カスタムシリコン）、CUDAとTritonの高性能Kernel（FlashAttention、融合Kernel）、MLコンパイラ（PyTorch 2.0、JAX/XLA、TensorRT）
- **学習と推論（第6-11章）**: 分散学習（DDP/FSDP、テンソル/パイプライン/シーケンス/エキスパート並列）、NCCL集合通信とネットワーク（NVLink/NVSwitch、InfiniBand/RoCEv2）、学習システムエンジニアリング（フォールトトレランス、チェックポイント、混合精度）、推論最適化（vLLM、PagedAttention、Continuous Batching、KV Cache）、モデル量子化（GPTQ、AWQ、SmoothQuant）と圧縮
- **データとプラットフォーム（第12-15章）**: RAGとベクトル検索、AIストレージとデータエンジニアリング、クラスター設計とスケジューリング（SLURM、K8s GPUスケジューリング）、クラウドネイティブMLOpsとAIプラットフォーム
- **計測と実践（第16-18章）**: パフォーマンス指標とMFU分析、AIインフラ理論計算ハンドブック（FLOPs、メモリ計画、通信帯域、コスト見積もり）、大規模AIクラスター構築実践

> AIインフラエンジニア、学習/推論プラットフォーム開発者、システムアーキテクト、分散システム実務者向け。

## ☁️ クラウドコンピューティング権威ガイド

仮想化からマルチクラウド戦略までのクラウドコンピューティング全スタック知識体系。AWS、Azure、GCP、Alibaba Cloud、Tencent Cloud、Huawei Cloudの実製品を起点に、アーキテクチャ原理と設計トレードオフを解説します。

- **基礎（第1-3章）**: クラウドの定義と経済性、仮想化技術（CPU/メモリ/I/O、KVMとQEMU）、サービスモデル（IaaS/PaaS/Serverless/CaaS）と選定フレームワーク
- **リソースサービス（第4-7章）**: コンピュートサービス（インスタンスファミリー、オートスケーリング、スポットインスタンス、ベアメタル）、クラウドストレージ（ブロック/オブジェクト/ファイル、整合性設計、バックアップとDR）、クラウドネットワーク（VPC、ロードバランシング、CDN、DNS）、コンテナ技術（Namespace/Cgroups、ランタイム、CNI/CSI、イメージ配布）
- **プラットフォームとデータ（第8-13章）**: クラウドネイティブ設計パターン、Kubernetesオーケストレーション、サービスメッシュとマイクロサービス、クラウドデータベース、メッセージングとイベント駆動、ビッグデータとAI
- **ガバナンスと運用（第14-18章）**: クラウドセキュリティとコンプライアンス、オブザーバビリティ、DevOpsとプラットフォームエンジニアリング、FinOpsコストガバナンス、マルチクラウド設計とマイグレーション

> クラウドアーキテクト、バックエンドエンジニア、SRE、DevOpsエンジニア、技術マネージャー向け。

## 🦾 エンボディドインテリジェンス権威ガイド

剛体力学からVLA基盤モデルとロボティクスまでの体系的な権威リファレンス。第一原理から出発し、古典手法と最前線を橋渡しし、各手法を形式化・数学導出・エンジニアリング実装の順で解説します。

- **基礎と概要（第1-3章）**: 定義と核心的科学問題、剛体運動と力学（姿勢表現、リー群、運動学と動力学、接触と摩擦）、ロボットハードウェアとシステムアーキテクチャ
- **知覚と制御（第4-7章）**: マルチモーダル知覚（視覚/触覚/力覚/自己受容）、状態推定とSLAM、ニューラルシーン表現、運動計画とモデル予測制御、把持と巧緻操作
- **エンボディド基盤モデル（第8-12章）**: 世界モデル、強化学習、模倣学習（拡散ポリシー、アクションチャンキング）、視覚言語モデル（VLM）、視覚言語動作モデル（VLA）
- **システムと展開（第13-18章）**: データエンジンとSim-to-Real転送、学習インフラ、エッジ展開とモデル圧縮、安全性・アライメント・評価、産業動向とヒューマノイドロボット商業化

> ロボティクス、自動運転、AIのエンジニア・研究者、エンボディドインテリジェンスの産業化を追うプロダクト・投資関係者向け。

## ✨ 特徴

- **体系性** — 4冊とも各18章＋4付録、原理から実践まで完全な知識体系をカバー。教材やチーム育成にも最適
- **クロスベンダー／クロスモデル比較** — 同一問題（オブジェクトストレージ整合性、マネージドK8s、Serverlessコールドスタート、各社GPUとアクセラレータ…）の実装を横断比較し、共通パターンを抽出
- **原理駆動** — Transformerアテンション、GPUマイクロアーキテクチャ、分散学習の並列戦略、仮想化、Kubernetesスケジューリングなど、使用面にとどまらない深い機構解説
- **コードレベル詳細** — Kernel/ソースレベルの実装詳細、アーキテクチャ決定の背後にあるトレードオフの論理
- **エンジニアリング実践** — パフォーマンスエンジニアリング、FinOpsコストガバナンス、フォールトトレラント学習、推論最適化、オブザーバビリティ、Sim-to-Real転送など本番対応能力
- **継続的進化** — 最新オープンソースモデル（DeepSeek-V4、Kimi K3、Qwen、GLM）、GPUマイクロアーキテクチャ、万GPUクラスター、VLA基盤モデルなどの業界最前線を追跡
