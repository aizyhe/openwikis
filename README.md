## 🧠 《AI 算法权威指南》

从 Transformer 架构到大模型算法与智能系统的权威指南。以 Transformer 为起点，兼顾理论推导与工程落地，紧跟 2026 年最新开源架构案例。

- **架构基础（第 1-4 章）**：Transformer 原理与数据流、文本/图像/语音 token 化与位置编码（RoPE、ALiBi）、前馈网络与归一化等核心组件、自回归生成与解码策略
- **训练与规模化（第 5-9 章）**：训练与优化、预训练与数据（合成数据、缩放法则）、后训练对齐（SFT/RLHF/DPO）、现代大模型架构（MoE、混合与线性注意力）、前沿模型案例（DeepSeek-V4、Kimi K3、Qwen 3.8 Max、GLM 5.3）
- **高效推理与生成（第 10-14 章）**：长上下文与 KV Cache、投机解码、强化学习原理、推理增强与思维链、生成式模型（扩散语言模型）、多模态（VLM/VLA）
- **智能系统与工程（第 15-18 章）**：Agent 系统与认知架构、世界模型、安全与评估、FlashAttention 的 GPU 级高效实现

## ⚡ 《AI Infra 权威指南》

从 GPU 微架构到万卡集群的全链路 AI 基础设施。以 NVIDIA、Google、Meta、Microsoft 的公开技术报告与开源系统为参考，兼顾代码级细节与工程取舍。

- **基础与 GPU 微架构（第 1-4 章）**：AI Infra 全景与 Scaling Law、SIMT/SIMD 范式、NVIDIA GPU 架构演进（SM、Tensor Core、Warp 调度、内存层次）、AI 加速器生态（AMD ROCm、Google TPU、云厂商/互联网自研芯片）、CUDA 与 Triton 高性能 Kernel（FlashAttention、融合 Kernel）
- **分布式训练与通信（第 5-8 章）**：数据并行（DDP/FSDP）、模型并行（张量/流水线/序列/专家并行）、5D 并行组合、DeepSpeed ZeRO、集合通信（NCCL 内部机制、NVLink/NVSwitch、InfiniBand/RoCEv2）、万卡训练稳定性、容错与分布式检查点、混合精度训练
- **推理与模型优化（第 9-12 章）**：推理引擎（vLLM、PagedAttention、Continuous Batching、KV Cache）、模型量化（GPTQ、AWQ、SmoothQuant）、稀疏化与知识蒸馏、RAG 与向量检索、AI 存储与数据工程
- **平台与框架优化（第 13-16 章）**：AI 集群拓扑与调度（SLURM、K8s GPU 调度）、云原生 MLOps、ML 编译器（TorchDynamo、JAX/XLA、TensorRT）、性能工程与成本优化
- **设计与实践（第 17-18 章）**：AI Infra 理论计算手册（FLOPs、显存规划、通信带宽、成本估算）、大规模 AI 集群建设实战

## ☁️ 《云计算权威指南》

从虚拟化到多云战略的全栈云计算知识体系。以 AWS、Azure、GCP、阿里云、腾讯云、华为云六大主流云厂商的实际产品为锚点，深入剖析架构原理与设计取舍。

- **基础（第 1-3 章）**：云计算定义与经济学本质、虚拟化技术（CPU/内存/I/O、KVM 与 QEMU）、云服务模型（IaaS/PaaS/Serverless/CaaS）与选型框架
- **资源服务（第 4-7 章）**：计算服务（实例族、弹性伸缩、抢占式实例、裸金属）、云存储（块/对象/文件、一致性设计、备份容灾）、云网络（VPC、负载均衡、CDN、DNS）、容器技术（Namespace/Cgroups、运行时、CNI/CSI、镜像分发）
- **平台与数据（第 8-13 章）**：云原生设计范式、Kubernetes 编排、服务网格与微服务、云数据库、消息与事件驱动、大数据与 AI 落地
- **治理运营（第 14-18 章）**：云安全与合规、可观测性三支柱、DevOps 与平台工程、FinOps 成本治理、多云架构与迁移

## 🦾 《具身智能权威指南》

从刚体动力学到 VLA 大模型与机器人的系统权威参考。从第一性原理出发，贯通经典与前沿，让读者「知其然，更知其所以然」。

- **基础与总览（第 1-3 章）**：具身智能定义与核心科学问题、刚体运动与动力学（位姿表示、李群 SO(3)/SE(3)、运动学动力学）、机器人硬件与系统架构
- **感知与建模（第 4-6 章）**：视觉/触觉/本体多模态感知、环境感知与状态估计（SLAM）、世界模型与神经场景表示
- **学习与控制（第 7-10 章）**：强化学习、模仿学习、运动规划与底层控制、灵巧操作与接触
- **具身大模型（第 11-14 章）**：视觉语言模型（VLM）、视觉-语言-动作模型（VLA）、具身数据引擎、仿真与 Sim-to-Real 迁移
- **系统与落地（第 15-17 章）**：具身训练基础设施、部署与边缘推理、安全对齐与评估
- **产业与展望（第 18 章）**：产业格局、人形机器人、商业化路径与开放问题

## ✨ 核心特点

- **跨厂商对比** — 对同一问题（对象存储一致性、托管 K8s、Serverless 冷启动……）横向比较各厂商实现，提炼通用架构规律
- **原理驱动** — 深入虚拟化、分布式存储一致性、SDN、Kubernetes、服务网格、GPU 微架构、大模型训练/推理等底层机制
- **代码级细节** — 讲原理到代码级实现，谈架构讲清工程取舍背后的权衡逻辑
- **工程实战** — 覆盖性能工程、FinOps 成本治理、容错训练、可观测性、仿真到真实迁移等生产化落地能力
- **持续演进** — 跟踪 GPU 微架构、万卡集群、推理优化、量化压缩、VLA 大模型等行业最新进展
