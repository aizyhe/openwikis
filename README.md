## 🧠 《AI 算法权威指南》

从 Transformer 到大模型智能系统的算法全链路指南，理论推导与工程实践并重，紧跟 2026 年最新开源架构。

- **架构基础（第 1-4 章）**：Transformer 原理与数据流、文本/图像/语音 token 化与位置编码（RoPE、ALiBi）、前馈网络与归一化等核心组件、自回归生成与解码策略
- **训练与规模化（第 5-9 章）**：训练与优化、预训练与数据（合成数据、缩放法则）、后训练对齐（SFT/RLHF/DPO）、现代大模型架构（MoE、混合与线性注意力）、前沿模型案例（DeepSeek-V4、Kimi K3、Qwen 3.8 Max、GLM 5.3）
- **高效推理与生成（第 10-14 章）**：长上下文与 KV Cache、投机解码、强化学习原理、推理增强与思维链、生成式模型（扩散语言模型）、多模态（VLM/VLA）
- **智能系统与工程（第 15-18 章）**：Agent 系统与认知架构、世界模型、安全与评估、FlashAttention 的 GPU 级高效实现

> 适合大模型算法工程师、NLP/多模态研究员、想系统掌握 Transformer 与推理优化的从业者。

## ⚡ 《AI Infra 权威指南》

从 GPU 微架构到万卡集群的 AI 基础设施全链路参考，以 NVIDIA、Google、Meta、Microsoft 公开技术报告与开源系统为依据，兼顾代码级细节与工程取舍。

- **硬件与软件（第 1-5 章）**：AI Infra 全景与 Scaling Law、GPU 微结构（SIMT/SIMD、SM 与 Warp 调度、内存层次、Tensor Core）、AI 加速器生态（AMD ROCm、Google TPU、自研芯片）、CUDA 与 Triton 高性能 Kernel（FlashAttention、融合 Kernel）、ML 编译器（PyTorch 2.0、JAX/XLA、TensorRT）
- **训练与推理（第 6-11 章）**：分布式训练（DDP/FSDP、张量/流水线/序列/专家并行）、NCCL 集合通信与网络（NVLink/NVSwitch、InfiniBand/RoCEv2）、训练系统工程（容错、检查点、混合精度）、推理优化（vLLM、PagedAttention、Continuous Batching、KV Cache）、模型量化（GPTQ、AWQ、SmoothQuant）与压缩
- **数据与平台（第 12-15 章）**：RAG 与向量检索、AI 存储与数据工程、集群拓扑与调度（SLURM、K8s GPU 调度）、云原生 MLOps 与 AI 平台
- **度量与实践（第 16-18 章）**：性能指标体系与 MFU 分析、AI Infra 理论计算手册（FLOPs、显存规划、通信带宽、成本估算）、大规模 AI 集群建设实战

> 适合 AI 基础设施工程师、训练/推理平台开发者、系统架构师与分布式系统从业者。

## ☁️ 《云计算权威指南》

从虚拟化到多云战略的云计算全栈知识体系，以 AWS、Azure、GCP、阿里云、腾讯云、华为云六大主流云厂商实际产品为锚点，剖析架构原理与设计取舍。

- **基础（第 1-3 章）**：云计算定义与经济学本质、虚拟化技术（CPU/内存/I/O、KVM 与 QEMU）、云服务模型（IaaS/PaaS/Serverless/CaaS）与选型框架
- **资源服务（第 4-7 章）**：计算服务（实例族、弹性伸缩、抢占式实例、裸金属）、云存储（块/对象/文件、一致性设计、备份容灾）、云网络（VPC、负载均衡、CDN、DNS）、容器技术（Namespace/Cgroups、运行时、CNI/CSI、镜像分发）
- **平台与数据（第 8-13 章）**：云原生设计范式、Kubernetes 编排、服务网格与微服务、云数据库、消息与事件驱动、大数据与 AI 落地
- **治理运营（第 14-18 章）**：云安全与合规、可观测性三支柱、DevOps 与平台工程、FinOps 成本治理、多云架构与迁移

> 适合云架构师、后端工程师、SRE、DevOps 工程师与技术管理者。

## 🦾 《具身智能权威指南》

从刚体动力学到 VLA 大模型与机器人的系统权威参考，从第一性原理出发贯通经典与前沿，讲清每个方法从形式化、数学推导到工程实现的完整链路。

- **基础与总览（第 1-3 章）**：具身智能定义与核心科学问题、刚体运动与动力学（位姿表示、李群、运动学动力学、接触与摩擦）、机器人硬件与系统架构
- **感知与控制（第 4-7 章）**：视觉/触觉/力觉/本体多模态感知、状态估计与 SLAM、神经场表示等环境感知、运动规划与模型预测控制、抓取与灵巧操作
- **具身大模型（第 8-12 章）**：世界模型、强化学习、模仿学习（扩散策略、动作分块）、视觉语言模型（VLM）、视觉-语言-动作模型（VLA）
- **系统与落地（第 13-18 章）**：数据引擎与仿真迁移（Sim-to-Real）、训练基础设施、边缘部署与模型压缩、安全对齐与评估、产业格局与人形机器人商业化

> 适合机器人、自动驾驶、AI 领域工程师与研究者，以及关注具身智能产业化的产品与投资人士。

## ✨ 核心特点

- **系统性** — 四本书各 18 章 + 4 附录，从原理到实战覆盖完整知识体系，可作教学参考与团队培训教材
- **跨厂商/跨模型对比** — 对同一问题（对象存储一致性、托管 K8s、Serverless 冷启动、各家 GPU 与加速器……）横向比较实现，提炼通用规律
- **原理驱动** — 深入 Transformer 注意力机制、GPU 微架构、分布式训练并行策略、虚拟化、Kubernetes 调度等底层机制，不只停留在使用层
- **代码级细节** — 讲原理到 Kernel/源码级实现，谈架构讲清工程取舍背后的权衡逻辑
- **工程实战** — 覆盖性能工程、FinOps 成本治理、容错训练、推理优化、可观测性、仿真到真实迁移等生产化落地能力
- **持续演进** — 跟踪最新开源模型（DeepSeek-V4、Kimi K3、Qwen、GLM）、GPU 微架构、万卡集群、VLA 大模型等行业前沿
