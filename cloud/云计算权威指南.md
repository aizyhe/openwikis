## 关于本书

云计算经过近二十年的发展，已从一种新兴技术演进为数字经济的核心基础设施。上云已成技术战略的默认选项，但云计算的真正挑战不在于「用云」，而在于「用好云」——理解虚拟化的本质、掌握分布式存储的一致性模型、设计跨可用区的高可用网络拓扑、在数百种云服务中做出兼顾性能与成本的架构决策。这些能力无法通过阅读产品文档获取，需要一套将技术原理与工程实践融为一体的知识体系。

本书旨在成为云计算领域的系统性权威参考。全书共 18 章，划分为四大部分，以 AWS、Azure、GCP、阿里云、腾讯云、华为云六大主流云厂商的实际产品为锚点，深入剖析背后的架构原理与设计取舍。本书不是产品手册的罗列，而是关注「为什么这样设计」「各厂商如何解决同一问题」「如何根据场景做出最优选择」。

第一部分「基础」（第 1-3 章）从云计算的定义与经济学本质、演进历程与部署模型深度对比、全球市场格局，到区域与可用区架构、责任共担模型与采用框架，建立理解云计算的技术底座；随后深入 CPU、内存、I/O 三种虚拟化的实现机制与性能调优，剖析 KVM 与 QEMU 架构、轻量级虚拟化与硬件加速方案；最后厘清 IaaS、PaaS、Serverless、CaaS 等服务模型的控制面架构，讲解资源编排引擎、服务目录与配额管理，并给出服务模型选型框架。

第二部分「资源服务」（第 4-7 章）覆盖云计算的核心资源。计算服务围绕实例族体系、物理机资源池化与调度、弹性伸缩引擎、抢占式实例经济学、裸金属与云上 HPC，并单列 GPU 云服务器的完整技术栈；云存储从存储介质讲起，深入块、对象、文件三种形态的架构与一致性设计，覆盖数据保护、备份容灾、大规模迁移、混合云存储加速与成本模型；云网络讲解 VPC 控制面与数据面加速、负载均衡、全球互联、CDN 与 DNS 体系；容器技术从 Namespace 与 Cgroups 出发，覆盖镜像内幕、容器运行时、安全容器、CNI 与 CSI、镜像分发加速与 BuildKit 构建引擎。

第三部分「平台与数据」（第 8-13 章）先阐明云原生设计范式（CNCF 全景、12-Factor、不可变基础设施、声明式控制回路、弹性模式与成熟度模型）；随后覆盖 Kubernetes 编排（控制回路、调度器、资源 QoS、弹性伸缩、托管服务对比与大规模集群优化）、服务网格与微服务治理（数据面代理、流量治理、API 网关与厂商对比）、云数据库的分布式架构（云原生关系型、分布式数据库、缓存、NoSQL、时序与向量数据库）、消息与事件驱动系统（Kafka 剖析、事件总线、流计算、CDC 与消息 SLA），以及大数据与 AI 在云上的落地形态（数据湖、批流计算、LLM 训练与推理、RAG 与 Agent 编排）。

第四部分「治理运营」（第 14-18 章）解决生产化落地的系统性挑战。云安全覆盖纵深防御、IAM、密钥管理、网络威胁防护、数据安全治理与机密计算；可观测性围绕 Metrics、Tracing、Logging 三支柱与 eBPF、SRE/SLO 展开；DevOps 与平台工程讲解 CI/CD、基础设施即代码、GitOps 与内部开发者平台；FinOps 给出计费体系、成本可视化与各资源域的成本优化模型；最后讨论多云与混合云战略、跨云互联、云迁移方法论与灾备双活体系。

本书在写作中注重跨厂商对比视角，对同一类问题（如对象存储的一致性模型、托管的 Kubernetes 服务差异、Serverless 冷启动优化策略）横向比较各厂商的实现方案，帮助读者建立云厂商无关的架构判断力。附录提供术语与缩略语速查、厂商产品对照、架构决策框架与电商大促综合案例。
